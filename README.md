# ICcard — Asaca 残高チェッカー (Android)

旭川電気軌道の Asaca（FeliCa）を Android で読むアプリ。

## インストール
Releases の「latest」から `ICcard.apk` をスマホで開いてインストールする（提供元不明アプリの許可が必要）。
main に push すると GitHub Actions が自動でビルドして latest を更新する。

## 使い方
1. カードを背面にかざす → 鍵なしで読める領域を全部ダンプして表示
2. 「今の残高を教える」に、そのときの残高を入力 → カード内から一致する場所を探す
3. 候補が複数なら、乗車やチャージの後にもう一度かざして残高を入力 → 絞り込み
4. 1つに決まったら、以後はかざすだけで残高が大きく表示される

前回のダンプとの差分も表示されるので、履歴ブロックの解析にも使える。
「ダンプを共有」で直近3回分をテキストで送れる。
